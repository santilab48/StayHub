ช่องกรอกแบบ `type="number"` ใช้แป้นเลขของเบราว์เซอร์มือถือ ส่วนช่องมิเตอร์ที่เป็นข้อความใช้ `inputMode="decimal"`. การคำนวณยอดตัวอย่างยังแสดงระหว่างกรอกด้วยสูตรเดิม; ค่าที่ส่งบันทึกจึงแปลงเป็นเลขเมื่อกดบันทึก ไม่แปลงใน `onChange`.

## ขอบเขตที่ยังไม่ได้ทดสอบผ่าน Browser

- หน้าแจ้งชำระของผู้เช่าที่เป็น Placeholder และ Local Workspace ไม่มีการทดสอบกรอกตัวเลขในรอบนี้; ตรวจโค้ดว่าค่าเริ่มต้นว่างอยู่แล้ว
- ยังไม่ได้ทดสอบการวางข้อความที่ไม่ใช่ตัวเลขหรือรูปแบบ locale ด้วย Browser ทุกช่อง; validation เดิมของเบราว์เซอร์และ Backend ยังคงอยู่
- ไม่ได้ทดสอบบน Railway Staging หรืออุปกรณ์มือถือจริง

ไม่มีการเปลี่ยนสูตรคำนวณ เงื่อนไขทางการเงิน API, Migration, ฐานข้อมูล Production, ระบบพิมพ์ หรือข้อความนักพัฒนา
