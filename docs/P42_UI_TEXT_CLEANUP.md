## ข้อความที่ปรับ

- ห้องพัก บิล ใบเสร็จ งานบริการ และสมาชิก: นำคำอธิบาย PostgreSQL, Neon, Railway, Server และ API ออกจากข้อความที่ผู้ใช้เห็น เปลี่ยนเป็นคำอธิบายงานที่ทำได้จริง
- ใบเสร็จ: คงคำเตือนว่าออกได้เฉพาะบิลชำระครบ และไม่ออกใบเสร็จสำหรับยอดค้าง
- Workspace และการสำรอง: ใช้ “ฉบับร่าง”, “ข้อมูลออนไลน์”, “บัญชีของคุณ” และ “กู้คืนข้อมูล”; คงคำเตือนว่าการกู้คืนแทนที่ข้อมูลในเครื่องและต้องตรวจการเชื่อมที่พักอีกครั้ง
- สถานะรายการ: แสดงสถานะงานซ่อม รถ พัสดุ บิล และรายการรอซิงก์เป็นภาษาไทยแทนรหัสสถานะภายใน
- Placeholder ประเภทห้องและเตียงรายคืน: เปลี่ยนตัวอย่างภาษาอังกฤษเป็นตัวอย่างภาษาไทย
- Error ของหน้าเจ้าของและใบเสร็จ: แปลข้อความที่รู้จัก เช่น `Bill list unavailable` และปิดข้อความเทคนิคที่ไม่รู้จักด้วยคำแนะนำภาษาไทยทั่วไป โดยไม่เปลี่ยน API response หรือ technical logs
- คงคำเตือน Preview ว่าเป็นข้อมูลตัวอย่าง และคงข้อความกฎหมาย/การเงินบนเอกสารเดิม

## ข้อจำกัด

- หน้าใบเสร็จรายฉบับที่ต้องมีบิลชำระครบไม่ได้เปิดด้วยข้อมูลจริงในรอบนี้; ตรวจข้อความใน Source และทดสอบ Error ของหน้ารายการใบเสร็จ
- ไม่ได้ทดสอบทุก Error ที่อาจตอบกลับจากบริการภายนอก แต่มีตัวกรองไม่ให้ข้อความเทคนิคที่ไม่รู้จักแสดงในจุดที่แก้
- หน้า Platform Admin และหน้ามรดกที่ Redirect ไป `/cloud` หรือ `/my` อยู่นอกขอบเขตเจ้าของ/ผู้เช่ารอบนี้
- ไม่ได้ทดสอบบน Railway Staging หรืออุปกรณ์มือถือจริง และไม่มีการ Deploy

ไม่ได้แก้ Business Logic, API, ฐานข้อมูล, การพิมพ์เอกสาร หรือ Technical Logs
